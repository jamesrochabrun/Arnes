# arnes

Model-adaptive agent harness on [OpenRouter](https://openrouter.ai) — an interactive
agent CLI where the chosen model drives the wire dialect, prompt pack, and request shape.

```sh
bun add -g arnes    # or: npm install -g arnes
arnes               # interactive REPL (needs OPENROUTER_API_KEY)
```

This package is a thin launcher: the native binary for your platform installs through
one of the optional dependencies (macOS arm64/x64, Linux x64/arm64).

Full documentation: https://github.com/jamesrochabrun/Arnes
